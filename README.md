# Лендинг «СитиАрбитр» — банкротство физических лиц

Одностраничный сайт с анимацией по скроллу: разрозненные долговые документы собираются в папку «Дело о банкротстве».

- Один файл `index.html`, без сборки и сторонних библиотек.
- Тексты составлены с учётом ст. 28.1 ФЗ «О рекламе» (с 01.01.2026): без обещаний освобождения от долгов, с обязательным предупреждением о последствиях банкротства.
- Фирменные цвета меняются в начале `<style>` (переменные `--brand*`).
- Логотип: положить `logo.svg` рядом с `index.html` и раскомментировать `<img>` в шапке.
- Форма заявки пока без отправки — место для подключения Битрикс24 (вебхук `crm.lead.add`) отмечено в коде.
