# Лендинг «СитиАрбитр» — банкротство физических лиц

Одностраничный сайт с интерактивом:

- Первый экран «Телефон»: уведомления от кредиторов сыплются на экран, их можно смахивать; кнопка «Передать дело юристу» успокаивает экран и сводит все нити к юристу.
- Блок «Ваш реестр» перед формой: посетитель отмечает долги и доход, видит долговую нагрузку; кнопка «Перенести в заявку» подставляет данные в форму.

- Один файл `index.html`, без сборки и сторонних библиотек.
- Тексты составлены с учётом ст. 28.1 ФЗ «О рекламе» (с 01.01.2026): без обещаний освобождения от долгов, с обязательным предупреждением о последствиях банкротства.
- Фирменные цвета меняются в начале `<style>` (переменные `--brand*`).
- Логотип: `logo.svg` (он же иконка вкладки), в шапке встроен в код.
- Форма заявки пока без отправки. Поля лида для Битрикс24 (`crm.lead.add`) уже собирает функция `buildLead()`: имя, телефон и комментарий с данными калькулятора. Осталось вписать адрес вебхука.
- Шрифты: заголовки Unbounded, основной текст Onest.
